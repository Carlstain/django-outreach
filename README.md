# django-outreach

A reusable Django app for prospects and bulk mail: prospects with an optional link to your user model, `{{ first_name | fallback }}` style variables, a rich text message body, a log of every mailing and one-click unsubscribe links, served by its own admin site.

Work in progress: the package is being extracted from a production CRM and is not usable yet. Installation and configuration are documented here once the first version lands.
